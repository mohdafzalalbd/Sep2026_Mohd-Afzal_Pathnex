#Jenkinsfile — With Git Integration and Testing

```groovy
pipeline {
    agent any
    stages {
        stage('Clone Repository') {
            steps {
                git 'https://github.com/afzal/sample-repo.git'
            }
        }
        stage('Build') {
            steps {
                echo 'Building project from Git repository'
            }
        }
        stage('Test') {
            steps {
                echo 'Running unit tests'
            }
        }
        stage('Deploy') {
            steps {
                echo 'Deploying application'
            }
        }
    }
}

Ansible — Create User and Set Permissions

- name: Create a new user
  hosts: all
  become: yes
  tasks:
    - name: Create user
      user:
        name: afzal
        state: present
        shell: /bin/bash
    - name: Set permissions for the user
      file:
        path: /home/afzal
        owner: afzal
        group: afzal
        mode: '0755'

Terraform — EC2 with Tags and Volume
